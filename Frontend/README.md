# BugShield Frontend

The BugShield frontend is a static Web3 interface that connects to the `BugBounty` Solidity contract through MetaMask and ethers.js.

## Pages

- `index.html` — landing page.
- `how-it-works.html` — on-chain workflow and contract behavior.
- `app.html` — live BugShield DApp.

## Run

### Windows

Double-click `run.bat`.

It shows the currently configured contract address, then asks for a new one: paste a `0x...` address + Enter to update `app.html` and start, or press Enter empty to keep the current address and just start. Invalid input is rejected and asked again.

The launcher tries `py`, `python`, and then `npx http-server`, using whichever local runtime is available. It serves the folder on port `8000` and opens the browser automatically.

### Manual Python

```powershell
cd Frontend
python -m http.server 8000
```

Then open:

```text
http://localhost:8000/
```

## Sepolia

The DApp is configured for Sepolia:

- Chain ID: `11155111`
- Hex Chain ID: `0xaa36a7`

MetaMask network changes and account changes are handled by the frontend.

## Contract Address

`app.html` contains the `CONTRACT_ADDRESS` constant for the deployed BugShield contract. The easiest way to update it is `run.bat` (paste + Enter). You can also run `py set_contract.py <address>` directly, or edit the constant by hand with the full 42-character contract address.

Do not replace it with your wallet address.

## Live Contract Actions

The DApp uses the contract's real methods:

- `createBounty`
- `submitReport`
- `resolveBounty`
- `cancelBounty`
- `getBounty`
- `bountyCount`
- `bounties`

No fake transaction or bounty data is generated by the frontend.
